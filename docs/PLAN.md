# Сосед на бутылке — план разработки

Дружеский стёб-стелс: сосед в очередной раз «завязал», а мы за день незаметно доводим его до пьяного концерта.
Цель: 1–2 уровня, но максимально красивые и смешные.

## Стиль: что берём и что делаем своё

**Берём (жанр и ощущение):**
- квартира в разрезе: все комнаты видны сразу, видно, где сосед, а где мы;
- тёплая насыщенная мультяшная палитра, толстый контур, утрированные пропорции;
- стелс + пакости: сосед ходит по расписанию, мы готовим ловушки, пока он занят;
- слэпстик-реакции: преувеличенные гримасы, падения, вопли, длинные «сочные» анимации реакции;
- процент успеха уровня, цепочки пакостей, «люли», если поймал;
- озвучка-бормотание вместо речи, смешные звуки.

**Делаем своё (чтобы игра была нашей, а не копией):**
- свои персонажи: толстый «завязавший» сосед в майке и трениках, наш герой;
- современная квартира: PlayStation, ремонт, минералка, телефон;
- свои пакости вокруг алкоголя и «срывов»;
- свой интерфейс, своя музыка, свой юмор и реплики.

**Улучшаем:** плавнее анимации (cut-out-скелет вместо покадровых), пьяные эффекты экрана, частицы, тряска камеры.

## Технологии

- Godot 4.7, 2D, разрешение 1920×1080.
- Персонажи: cut-out-анимация (части тела + `Skeleton2D` / твины).
- Графика: генерация через OpenAI (ChatGPT) по единому стилевому промпту + бесплатные паки для интерфейса и частиц.
- Звук: freesound.org + генерация.
- Проверка: Godot MCP (запуск, ошибки), автоскриншоты (`--shot`, F12).
- Git → https://github.com/pulsestepdev-cpu/sosed_web

## Этапы

Каждый этап заканчивается коммитом, пушем и скриншотом. Пометка «Вы» означает, что нужно ваше участие.

### Этап 0. Подготовка ✅
- [x] Godot, Node.js, Godot MCP
- [x] Проект, git, GitHub
- [x] Автоскриншоты

### Этап 1. Дизайн-документ уровня 1
- [ ] Планировка квартиры: кухня, зал, ванная, коридор, балкон
- [ ] Список тайников (где лежит алкоголь) и предметов
- [ ] Список подмен и пакостей с результатом каждой
- [ ] Расписание соседа по шагам (что делает, где, сколько времени)
- [ ] Стадии опьянения и как меняется его поведение
- [ ] Комбо-цепочки
- [ ] Победа, провал, подсчёт очков
- [ ] **Вы:** читаете, правите, добавляете привычки знакомого

*Готово, когда* вы сказали «утверждаю».

### Этап 2. Прототип на квадратиках
- [ ] Квартира в разрезе из цветных блоков, двери между комнатами
- [ ] Герой: ходьба, переходы между комнатами, взаимодействие (клик/клавиша)
- [ ] Сосед: ходит по расписанию, выполняет действия у предметов
- [ ] Обзор соседа: видит в своей комнате, ловит → провал
- [ ] Укрытия: шкаф, штора, под столом

*Готово, когда* можно пройти по квартире, прятаться и быть пойманным.

### Этап 3. Пакости и опьянение
- [ ] Инвентарь, поиск в тайниках
- [ ] Подмены (минералка → водка и т.д.), срабатывание, когда сосед берёт предмет
- [ ] Шкала опьянения, стадии, смена поведения (шатается, хуже видит, роняет вещи)
- [ ] Комбо-цепочки
- [ ] Звуковые и текстовые заглушки реакций

*Готово, когда* уровень проходится от начала до конца на квадратиках и уже смешно.

### Этап 4. Интерфейс и игровой цикл
- [ ] Главное меню, пауза, экран победы и провала
- [ ] Счёт, «процент позора», список выполненных пакостей
- [ ] Подсказки (иконки над интерактивными предметами)
- [ ] Сохранение лучшего результата

### Этап 5. Стиль-гайд и графика
- [ ] Стилевой промпт (палитра, контур, пропорции)
- [ ] **Вы:** ключ OpenAI API (`OPENAI_API_KEY`) или ручная генерация в ChatGPT
- [ ] Концепты соседа и героя → **Вы:** выбираете вариант
- [ ] Персонажи по частям тела для cut-out-анимации
- [ ] Фоны комнат, предметы, интерфейс
- [ ] Замена квадратиков на графику

*Готово, когда* скриншоты выглядят как настоящая игра.

### Этап 6. Анимация и «сочность»
- [ ] Скелетная анимация: ходьба, питьё, шатание, падение, танец, сон, злость
- [ ] Анимации реакций на каждую пакость
- [ ] Пьяный фильтр экрана, частицы (пузыри, икота, звёздочки), тряска камеры
- [ ] Облачка реплик соседа
- [ ] Звуки и музыка

### Этап 7. Полировка уровня 1
- [ ] Баланс времени и сложности
- [ ] **Вы:** даёте поиграть знакомым, собираем отзывы
- [ ] Исправления, сборка `.exe`

### Этап 8. Уровень 2
- [ ] Дизайн-документ (вариант: «день рождения соседа» или «гараж/дача»)
- [ ] Повтор этапов 2–7 для новой локации
