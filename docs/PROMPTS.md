# Промпты для ChatGPT

## Как генерировать

1. **Всё делайте в одном чате.** ChatGPT помнит стиль внутри разговора.
2. **Первым сообщением отправьте «Стиль игры» (блок 0).** Дальше просто шлите промпты по очереди.
3. **Когда выберете финальный вариант персонажа, прикладывайте эту картинку** ко всем следующим промптам с ним (кнопка «+» / скрепка) и пишите «вот этот персонаж».
4. **Фон.** Прозрачный ChatGPT не делает, поэтому персонажи и предметы рисуются на однотонном фоне, а я его убираю сам:
   - обычно **ярко-зелёный (#00FF00)**;
   - если на картинке есть что-то зелёное (ополаскиватель, салат), фон **пурпурный (#FF00FF)**. В промптах ниже это уже учтено.
   - Комнатам (блок 5) однотонный фон не нужен.
5. **Сохраняйте файлы** в `assets/raw/` проекта с именами, указанными в скобках, например `assets/raw/hero_concept_1.png`. Или просто кидайте картинки в чат Claude, он сам разложит.
6. Если не нравится — просите исправить словами: «живот больше», «лицо добрее», «цвета теплее».

Порядок: **0 → 1 ✅ → 2 ✅ → 3 ✅ → 4 ✅ → 5 → 6.**

```
— толстый тёмно-коричневый контур одинаковой толщины;
— мягкая заливка с одним уровнем тени и лёгкими бликами, без фотореализма и без 3D;

— никакого текста, надписей, логотипов и брендов на картинках.

Ответь «стиль запомнил», картинку пока не рисуй.
```
